# LTV2 Foundation — Skeleton + Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up an isolated v2 Flask app (`ltv2/`) with its own database that a user can log into, with two roles, secure password hashing, session expiry, and account lockout.

**Architecture:** A new top-level Flask package `ltv2/` using the application-factory pattern, fully separate from the legacy `ltv_app/` and `localhost/`. Persistence via Flask-SQLAlchemy (SQLAlchemy 2.0 declarative) with Flask-Migrate/Alembic migrations against a dedicated SQLite file `instance/ltv2.db`. Authentication via Flask-Login; password hashing via argon2-cffi. Server-rendered Jinja templates. The legacy app and its live database (`instance/LTV Stocks.db`) are never touched.

**Tech Stack:** Python 3.13, Flask 3.1, Flask-SQLAlchemy 3.1+, SQLAlchemy 2.0, Flask-Migrate 4+ (Alembic), Flask-Login 0.6+, argon2-cffi, pytest, python-dotenv (config).

## Global Constraints

- **Isolation:** v2 code lives only under `ltv2/` + `flask_app_v2.py`. Never create or modify files under `ltv_app/` or `localhost/`.
- **Database file:** v2 uses `instance/ltv2.db` only. Never open, read, or write `instance/LTV Stocks.db`.
- **Roles:** exactly two — `admin` and `user`. Stored as a string column `role`. Admin gates: user management, lock/unlock, settings. Permission checks go through a decorator, never inline `role == "..."` scattered in views.
- **Password hashing:** argon2 (`argon2-cffi`'s `PasswordHasher`). Never store plaintext; never use werkzeug's default hashing.
- **Password rule:** minimum 8 characters (enforced at creation/change).
- **Account lockout:** after 5 consecutive failed logins, lock the account for 15 minutes. Successful login resets the counter.
- **Session expiry:** permanent sessions with a 60-minute inactivity timeout; activity refreshes the window.
- **Tests:** pytest. Every task ends green. Use an isolated temp SQLite DB per test session (never `instance/ltv2.db`).
- **Python entry point for Flask CLI:** `FLASK_APP=flask_app_v2.py`.
- **Naming:** new tables are unprefixed snake_case (`users`, not `tbl_user`) — this is a clean schema, not a copy of v1's `tbl_` convention. (v1→v2 data migration is a later plan and will map names explicitly.)

`ltv2/models/user.py`:
```python
from datetime import datetime
from argon2 import PasswordHasher
from argon2.exceptions import VerifyMismatchError, InvalidHashError
from flask_login import UserMixin
from ltv2.extensions import db

_ph = PasswordHasher()


class User(UserMixin, db.Model):
    __tablename__ = "users"

    id = db.Column(db.Integer, primary_key=True)
    username = db.Column(db.String(255), unique=True, nullable=False)
    email = db.Column(db.String(255))
    password_hash = db.Column(db.String(255), nullable=False)
    role = db.Column(db.String(20), nullable=False, default="user")
    failed_logins = db.Column(db.Integer, nullable=False, default=0)
    locked_until = db.Column(db.DateTime, nullable=True)

    def set_password(self, raw: str) -> None:
        self.password_hash = _ph.hash(raw)

    def check_password(self, raw: str) -> bool:
        try:
            return _ph.verify(self.password_hash, raw)
        except (VerifyMismatchError, InvalidHashError):
            return False

    @property
    def is_admin(self) -> bool:
        return self.role == "admin"
```

from flask import Blueprint, render_template, request, redirect, url_for, flash, session
from flask_login import login_user, logout_user, login_required
from ltv2.models.user import User

bp = Blueprint("auth", __name__)


@bp.route("/login", methods=["GET", "POST"])
def login():
    if request.method == "POST":
        username = request.form.get("username", "")
        password = request.form.get("password", "")
        user = User.query.filter_by(username=username).first()
        if user is None or not user.check_password(password):
            flash("Invalid username or password", "error")
            return redirect(url_for("auth.login"))
        login_user(user)
        session.permanent = True
        return redirect(url_for("main.index"))
    return render_template("auth/login.html")


@bp.route("/logout")
@login_required
def logout():
    logout_user()
    return redirect(url_for("auth.login"))
```

from functools import wraps
from flask import abort
from flask_login import current_user


def admin_required(view):
    @wraps(view)
    @login_required
    def wrapped(*args, **kwargs):
        if not current_user.is_admin:
            abort(403)
        return view(*args, **kwargs)
    return wrapped
```

### Task 5: Account lockout after failed logins

**Files:**
- Modify: `ltv2/blueprints/auth/views.py` (lockout logic in `login`)
- Test: `tests/ltv2/test_lockout.py`

**Interfaces:**
- Consumes: `current_app.config["MAX_FAILED_LOGINS"]`, `["LOCKOUT_MINUTES"]`; `User.failed_logins`, `User.locked_until`.
- Produces: login increments `failed_logins` on bad password; at `MAX_FAILED_LOGINS` sets `locked_until = now + LOCKOUT_MINUTES`. A locked user is refused even with the correct password until the window passes. Successful login resets `failed_logins=0`, `locked_until=None`.

- [ ] **Step 1: Write the failing test**

from ltv2.models.user import User


def _seed(app):

    u.set_password("password123")
    db.session.add(u); db.session.commit()
    return u


def test_lock_after_five_failures(client, app):
    _seed(app)
    for _ in range(5):
        client.post("/login", data={"username": "alice", "password": "wrong"})
    # correct password now refused because locked
    resp = client.post("/login", data={"username": "alice", "password": "password123"},
                       follow_redirects=True)
    assert b"locked" in resp.data.lower()
    u = User.query.filter_by(username="alice").first()
    assert u.locked_until is not None

    assert u.failed_logins == 0
    assert u.locked_until is None

    u.failed_logins = 5

        if user and user.locked_until and user.locked_until > now:
            flash("Account is locked. Try again later.", "error")
            return redirect(url_for("auth.login"))

        if user is None or not user.check_password(password):
            if user is not None:
                user.failed_logins = (user.failed_logins or 0) + 1
                if user.failed_logins >= current_app.config["MAX_FAILED_LOGINS"]:
                    user.locked_until = now + timedelta(
                        minutes=current_app.config["LOCKOUT_MINUTES"])
                from ltv2.extensions import db
                db.session.commit()
            flash("Invalid username or password", "error")
            return redirect(url_for("auth.login"))

        user.failed_logins = 0
        user.locked_until = None
        from ltv2.extensions import db
        db.session.commit()
        login_user(user)
        session.permanent = True
        return redirect(url_for("main.index"))
```

import click
from flask.cli import with_appcontext
from ltv2.extensions import db
from ltv2.models.user import User


@click.command("create-admin")
@click.argument("username")
@click.argument("email")
@click.argument("password")
@with_appcontext
def create_admin(username, email, password):
    if len(password) < 8:
        raise click.ClickException("Password must be at least 8 characters.")
    if User.query.filter_by(username=username).first():
        raise click.ClickException(f"User {username!r} already exists.")
    u = User(username=username, email=email, role="admin")
    u.set_password(password)
    db.session.add(u)
    db.session.commit()
    click.echo(f"Created admin {username!r}.")
```
